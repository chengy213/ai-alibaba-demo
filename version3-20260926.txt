🚀 新增功能 / 主要改动

1.仓库级项目指引 CLAUDE.md
- 浓缩 Version 1/2 与源码现状：技术栈、启动前提（Redis）、Agent 装配点、请求流、四个 Tool 行为、已知坑（如 CalculatorTool/Nashorn、流式 Round 0 空文本过滤等）。
- 给 Claude Code / 其他 AI 助手作为改代码前的「基底文档」，避免重复踩坑。

2.Claude Code 团队共享配置（.claude/settings.json）
- 权限：mvn / 常规 git 只读命令放行；git add/commit/push 等需询问；禁止直接读取 application.yml（保护 API Key）。
- Hook：执行 git commit 前自动 `mvn -q compile`，降低提交无法编译的代码的概率。
- 状态栏：展示当前 git 分支及是否有未提交改动。

3.斜杠命令
- `/run-app`：确认 Redis 可达后再启动 Spring Boot，失败时提示先起 Redis，不改连接配置。
- `/release-notes`：对照已有 version*.txt 风格，用 git log/diff 生成下一版中文发版说明。

4.SAA 审查 subagent（saa-reviewer）
- 专门审查 ReactAgent / @Tool / ChatController / AgentConfig 相关改动。
- 内置审查清单与已知坑（两套历史存储勿混淆、流式 Round 0 空文本属预期等），按 Critical/Major/Minor 输出。

5.spring-ai-alibaba Skill（渐进披露）
- SKILL.md 按「用户要做什么」指向三份 references，避免一次灌入全部上下文。
- 覆盖工具模式、Agent 装配、流式与对话历史三类高频改动场景。

📝 备注

- 本版本相对 version2：**无运行时行为变化**；查天气、备忘录、计算器、Redis 历史与 RedisSaver 会话记忆等能力与 version2 一致。
- version2 中已标注的已知问题（UserLocationTool 基本残废、CalculatorTool 在 JDK 17 下大概率不可用、API Key 明文等）仍存在，详见 CLAUDE.md「已知坑」。
- `.claude/settings.local.json` 仅本机使用，已加入 .gitignore，请勿提交。
